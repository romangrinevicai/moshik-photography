# 📥 Photos inbox

Drop Moshik's real photos here (GitHub → **Add file → Upload files**), and they
will be sorted, optimised and wired into the site.

**Best results**

- Original JPGs straight from Lightroom/the camera export (not screenshots and,
  if possible, not Facebook downloads — Facebook compresses heavily).
- Long edge of at least **2400 px**.
- Use sub-folders (or file-name prefixes) to say what each photo is:

```
photos-inbox/
  hero/              5–6 jaw-droppers for the home page slideshow (landscape)
  weddings/
  bar-bat-mitzvah/
  events/            brit, henna, engagements, birthdays…
  couples/           pre-wedding / save-the-date
  portraits/         family, maternity, personal
  corporate/
  about/             a portrait of Moshik + behind-the-scenes shots
  stories/<couple>/  8–20 photos from one event to feature as a full story
```

Only upload photos that the people in them are happy to see on a public website.
